# Oche

Darts zählen, gegen Bots spielen und trainieren – als Web-App für den iPhone-Home-Bildschirm.

**Installieren:** Die Seite in Safari öffnen, dann **Teilen → Zum Home-Bildschirm → Hinzufügen**.

- X01 (301/501/701, Double/Single/Master Out) und Cricket, mit Legs oder Sets
- Bots von Ø 20 bis Ø 110 in Fünferschritten
- Training: Rund um die Uhr, Bob's 27, Shanghai, Halve-It, 121, Checkout-Training, Scoring
- Läuft offline; Statistik bleibt nur auf dem Gerät
